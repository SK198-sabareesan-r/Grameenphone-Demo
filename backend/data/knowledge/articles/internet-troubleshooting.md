Check these before raising a ticket:
1. Mobile data is switched on and the customer has an active pack with data left (dial *121*1*4#).
2. Android APN: Settings > Mobile Network > Access Point Names. Create a profile with Name "GP" and APN "gpinternet", set it as default, restart the phone and switch mobile data on.
3. iPhone: Settings > General > Reset > Reset Network Settings (the phone password is needed).
4. Check for a network notice in the customer's area (see the customer card). If maintenance is in progress, give the expected fix time.
